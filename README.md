# Banking App CRUD Operation

A simple Banking Application built using Spring Boot that performs CRUD (Create, Read, Update, Delete) operations for bank accounts.

## Features

- Create Account
- View Account Details
- Update Account Information
- Delete Account
- REST API Support
- Layered Architecture

## Technologies Used

- Java
- Spring Boot
- Spring Web
- Spring Data JPA
- Maven
- MySQL
- Lombok
